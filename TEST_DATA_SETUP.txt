--------------------------------------------------------------------------------
AUTH FLOW (how it works)
--------------------------------------------------------------------------------

  1. scm-login-app  →  POST /auth/login  →  authService:8097
  2. authService    →  POST /api/users/validate  →  userService:8087
                       (validates username+password against PostgreSQL)
  3. authService    →  POST /realms/scm/protocol/openid-connect/token  →  Keycloak:8181
                       (grant_type=password, gets JWT)
  4. authService    →  GET /api/users/by-username/{username}  →  userService:8087
                       (enriches response with orgId, divisionId, etc. from MongoDB)
  5. authService    →  returns AuthResponse to scm-login-app
  6. scm-login-app  →  reads JWT claims (domainType, roleType, subscriptionType, tenantId)
                       to determine app routing and access

  Keycloak client : scm-backend (confidential, Direct Access Grants enabled)

  Realm           : scm
